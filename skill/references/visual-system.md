# 通用视觉系统

本文件是视觉规则的唯一来源，统一定义主题、画布、排版、角标、图标与输出方式。

## 视觉基调与主题色

采用米白或浅灰背景、近黑粗标题、白色模块卡片、线性图标、手写重点句和单一强调色。保持留白，同时设置明确的视觉组织中心，避免页面空洞。

用户指定风格或颜色时直接采用；未指定时按内容选择：

| 内容属性 | 推荐主题 | 主色 |
| --- | --- | --- |
| 概念科普、理论架构、技术原理 | 经典科技蓝 | `#1E60FF` |
| 学习心得、经验复盘、行动清单 | 温和成长绿 | `#2E8B57` |
| 避坑警告、重点提醒、效率技巧 | 活力橙 | `#F97316` |
| 专业报告、审美克制、品牌未知 | 极简黑白 | `#111827` |

同一套卡片只使用一个主色，并从主色推导浅色强调底、边框色和深色正文。默认令牌为：页面背景 `#FAFBFD`、卡片背景 `#FFFFFF`、主色 `#1E60FF`、浅色强调底 `#EAF0FF`、主文字 `#111827`、次文字 `#5B6475`、边框 `#D5DCE8`。用户提供色值时重新推导配套令牌，不混入默认科技蓝。

## 画布与文字

- 默认画布为 `1080×1440px`，严格保持 `3:4`。
- 内容安全区距四边至少 `72px`，底部为平台操作区增加留白。
- 主标题建议 `80–104px`，不超过两行。
- 二级小标建议 `34–44px`，正文建议 `26–32px`，辅助信息不小于 `22px`。
- 单页最多三级文字层级，正文目标为 80–150 个中文字符；不通过缩小字体塞入超量内容。
- 优先使用苹方、HarmonyOS Sans、思源黑体或其他授权清晰的无衬线字体。
- 优先使用准确自然的中文，只保留必要术语、品牌、模型、文件名、命令、代码和指标。

## 固定角标

- 右上角显示内容类别，优先逐字使用用户提供的 `系列名称`。
- 左下角保留署名区，优先逐字使用用户提供的 `博主署名`；不得附加系列名称或内容类别。
- 右下角统一使用 `XX/YY`，总页数等于实际页数。
- 博主署名和内容类别不得合并。

缺省决策：

| 用户输入 | 右上角 | 左下角 |
| --- | --- | --- |
| 两项均提供 | 逐字使用系列名称 | 逐字使用博主署名 |
| 只提供一项 | 使用已提供的系列名称，或生成 1–3 个单词的全大写英文类别 | 使用已提供的博主署名，或生成 2–4 个单词的全大写英文栏目短语 |
| 两项均未提供 | 生成与主题相关的全大写英文类别 | 生成不同于右上角、与主题相关的全大写英文栏目短语 |
| 明确要求留空 | 对应位置留空 | 对应位置留空 |

英文必须准确对应主题，不得虚构姓名、账号、机构或品牌归属。例如职业主题可使用右上角 `CAREER GUIDE`、左下角 `WORK & GROWTH`；AI 主题可使用右上角 `AI BASICS`、左下角 `AI FIELD NOTES`。

## 页面组件与信息结构

- 内容卡片使用白底、12–20px 圆角和 1–2px 边框，无阴影或极浅阴影。
- 重点句每页最多一句，可使用克制的手写字形和主题色下划线，不与主标题重复。
- 封面使用大标题、明确副标和一个相关主视觉，不留大面积无信息空白。
- 正文页设置 1 个主结构和 2–4 个支撑模块；线条、编号、图标和浅色强调区必须服务于阅读顺序。
- 每页只讲透一个主要模块，不为填充版面添加无信息文字。

按内容关系选择结构：

- 并列要点：2×2、2×3 或纵向清单。
- 先后关系：横向流程、纵向路线或时间轴。
- 差异辨析：左右对比或表格。
- 中心与组成：架构图或中心辐射。
- 原因与结果：因果链或问题树。
- 结论收束：一句核心结论配 3–5 个行动点。

## Lucide 图标

- 所有功能性图标统一使用 [Lucide](https://lucide.dev/icons)，不混用 Emoji、其他图标库或风格不一致的自绘图标。
- 原生 HTML/JavaScript 使用 `lucide`，React 使用 `lucide-react`，静态资源使用 `lucide-static`；最终图片必须离线可渲染，不依赖发布时访问 CDN。
- 当前环境没有 Lucide 包时，先检查已有依赖；无法取得官方图标时改用编号、文字标签或基础几何关系，不得自行绘制并声称是 Lucide。
- 线性 SVG 使用 `fill="none"`、`stroke="currentColor"`、默认描边宽度 `2`、圆角端点和圆角转角。
- 正文图标通常使用 32–48px，主视觉使用 48–72px；同页尺寸和全套语义映射保持一致。
- 图标颜色只使用主题色或正文色，不引入第二套强调色。
- 常用映射：喜欢用 `Heart`；优势或能力用 `BadgeCheck`、`Award`；用户或需求用 `Users`、`HandHeart`；时间用 `Clock3`；行动用 `ListChecks`、`MoveRight`；提醒用 `TriangleAlert`；工具用 `Wrench`、`NotebookTabs`。
- 导出前确认图标名称存在于当前安装版本，线条无裁切，并与文字基线、尺寸和间距一致。

## 输出方式与风格边界

- 文本、清单、对比、流程和结构图优先使用 HTML/CSS 或 SVG 渲染。
- 摄影、人物、插画、复杂场景或材质使用图像生成，再在可编辑布局中叠加中文文字。
- 全套统一主色、辅色、背景、字体层级、圆角、线条、页头和页脚，同时允许页面结构有节奏变化。
- 避免蓝紫渐变、霓虹、黑金、玻璃拟态和厚阴影，除非用户明确要求。
- 不擅自加入 Logo、人物形象、账号昵称、商业品牌或未经授权素材。
