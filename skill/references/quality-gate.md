# 质量门槛

最终导出前逐页检查。规则值以 `production-workflow.md` 和 `visual-system.md` 为准；本文件只负责验收。硬性项失败时先修复，不把页面标记为完成。

## 内容与流程

- [ ] 当前阶段符合三阶段门槛；未确认 P1/P2 时没有生成 P3 以后页面。
- [ ] 页面数量、顺序、标题和正文与已确认蓝图一致。
- [ ] 每页只有一个主要信息任务，结论先行，无重复解释和填充文字。
- [ ] 事实、数据、引语和用户经历与来源一致，推测已明确标注。
- [ ] 画面文字与已确认文案逐字一致，无错字、乱码或伪字。

## 视觉与品牌

- [ ] 全部页面符合已确认的画布、安全区、色彩令牌、字体层级、圆角、线条、页头和页脚规范。
- [ ] 原始尺寸和手机常见显示宽度下，标题、正文和辅助信息均可读，无裁切、溢出或遮挡。
- [ ] 封面缩略图能够识别主题；P2 能代表正文页的真实信息密度和版式系统。
- [ ] 页面存在明确的视觉组织中心，信息结构符合并列、流程、对比、层级或因果关系。
- [ ] 右上角、左下角和右下角分别符合角标决策，内容类别与署名没有合并。
- [ ] 英文只用于必要术语或缺省角标，含义与当前主题直接相关。
- [ ] 功能性图标来自 Lucide，名称存在、语义准确、描边统一且没有裁切。
- [ ] 没有混用 Emoji、其他图标库或伪装为 Lucide 的自绘图标。
- [ ] 没有擅自加入账号昵称、Logo、人物、商业品牌或未经授权素材。

## 导出与整套复检

- [ ] 页码连续，所有 `YY` 与实际总页数一致。
- [ ] 每页保留可编辑源文件，并导出尺寸一致、命名可排序的 PNG。
- [ ] 并列查看全套缩略图，确认主色、密度、留白和页面节奏一致。
- [ ] 记录失败页、失败项和修改结果；全部硬性项复检通过后再交付。
