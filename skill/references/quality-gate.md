# 质量门槛

在最终导出前逐页检查。任一硬性项失败时先修复，不将未通过的图片标记为完成。

## 硬性项

- [ ] 所有页面尺寸一致，默认为 1080×1440px。
- [ ] 所有内容位于安全区内，无裁切、溢出或遮挡。
- [ ] 每页只有一个主要信息任务。
- [ ] 标题、正文和注释在手机尺寸预览下可读。
- [ ] 画面中的文字与已确认文案逐字一致，无错字、乱码或伪字。
- [ ] 可以自然翻译的英文已改为中文，保留的英文均属于必要术语或专有名称。
- [ ] 事实、数据、引语和用户经历与来源一致，推测已明确标注。
- [ ] 页码连续，所有 `YY` 与实际总页数一致。
- [ ] 每页都有 `@思为的新世界` 与 `转行 AI 产品经理日记`。
- [ ] 同一套的主题色、字体层级、圆角、线条、页头和页脚一致。

## 编辑项

- [ ] 封面在缩略图尺寸下仍能识别选题，主标题不超过两行。
- [ ] 正文去掉了可删除的形容词、重复结论和空洞口号。
- [ ] 信息密度服务于阅读顺序，不使用过度平均的布局。
- [ ] 页面结构有节奏变化，但不破坏系列一致性。
- [ ] 图标、装饰线和页码不与核心内容争夺注意力。
- [ ] 手写重点句每页不超过一条，且不重复标题。
- [ ] 不存在无意义的蓝紫渐变、霓虹、厚阴影、玻璃拟态或装饰性英文。

## 视觉验收方法

1. 以原始尺寸检查文字、边界、图形和页码。
2. 将图片缩小到手机上常见的显示宽度，再次判断标题可读性与层级。
3. 将全套缩略图并列，检查主题色、留白、密度和页面节奏。
4. 记录失败页、失败项与修改结果，复检后再导出。
