# 质量门槛

最终导出前逐页检查。硬性项失败时先修复，不把未通过的页面标记为完成。

## 硬性项

- [ ] 所有页面尺寸一致，默认为 `1080×1440px`、`3:4`。
- [ ] 所有内容位于安全区内，无裁切、溢出或遮挡。
- [ ] 每页只有一个主要信息任务，正文目标为 80–150 个中文字符。
- [ ] 单页不超过三级文字层级，标题、正文和注释在手机尺寸预览下可读。
- [ ] 画面文字与已确认文案逐字一致，无错字、乱码或伪字。
- [ ] 事实、数据、引语和用户经历与来源一致，推测已明确标注。
- [ ] 页码连续，所有 `YY` 与实际总页数一致。
- [ ] `博主署名` 为空时没有署名或水印；非空时每页使用用户提供的同一文本。
- [ ] 同一套的主色、辅色、背景、字体层级、圆角、线条、页头和页脚一致。

## 编辑项

- [ ] 封面缩略图仍能识别主题，主标题不超过两行。
- [ ] P2 能代表正文页的真实信息密度和版式系统。
- [ ] 结论先行，删除重复解释、空洞口号和填充性形容词。
- [ ] 信息结构匹配内容关系，没有为了整齐而过度平均布局。
- [ ] 页面结构有节奏变化，同时保持系列一致。
- [ ] 图标、装饰线、署名和页码不抢夺核心内容注意力。
- [ ] 必要英文均属于术语或专有名称，不存在装饰性英文。
- [ ] 没有擅自加入账号昵称、Logo、人物、商业品牌或未经授权素材。

## 视觉验收

1. 以原始尺寸检查文字、边界、图形和页码。
2. 缩小到手机常见显示宽度，检查标题与正文可读性。
3. 并列查看全套缩略图，检查主色、留白、密度和页面节奏。
4. 记录失败页、失败项和修改结果，复检后再导出。
